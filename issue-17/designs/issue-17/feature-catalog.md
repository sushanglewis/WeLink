## 非功能需求

- **性能**：话题切换、Clarify 弹窗、Plan 卡片渲染前端响应 < 500ms；日程看板 iframe 首屏 < 3s。
- **安全**：iframe 启用 HTTPS、CSP、postMessage 白名单；token 不硬编码、可轮换、权限最小化；胶囊仅展示用户有权限的对象；日程操作按 token 权限收敛。
- **兼容性**：桌面端（Tauri/WebView）与 B/S 端表现一致；日程看板仅需 Web/iframe 可用，不要求移动端原生 SDK。
- **License 合规**：日程后端限定 MIT / Apache-2.0 / AGPL，排除 GPL 家族；最终选型经 PoC 与合规评审确认。
- **Agent 友好**：日历后端提供 CLI / REST API / MCP server / JMAP 至少一种可编程接口；agent 侧统一封装为 skill / MCP server / CLI，后端可替换。
- **国产化**：优先国内可部署或有商业买断路径的方案，遵循 issue-3/6/11/14 的国产化约束。
