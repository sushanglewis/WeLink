# UI 规格: issue-17

> 本规格基于已批准的 `design-review.md` 与 `feature-catalog.md`，为 HTML 原型与后续实现提供界面/交互依据。
>
> 2026-09-03 按 2026-09-02 领导会议纪要修订：新增独立工作台首页（区域 7）、督办催办/汇总卡片（区域 2）、组织化管理端约束（区域 8）；设计原则第 1 条由「IM 窗口即工作台」调整为「工作台首页 + IM 协同双入口」（PM 决策），待 PM 重新确认。

## 设计原则

1. **工作台首页 + IM 协同双入口**（2026-09-03 修订）：独立工作台首页是系统默认落地页，承载待办/通知/知识三模块；数字员工 IM 窗口是对外协同交流入口。首页内突出数字员工入口，保持数字员工的核心地位（回应纪要中路线坚持的关切）。
2. **桌面优先**：主要承载为 Tauri/WebView 桌面端，B/S 端保持一致布局。
3. **对话内轻交互**：话题、Clarify、Plan、胶囊均在消息层以卡片/选项卡/菜单形式呈现。
4. **iframe 嵌入复用**：日程看板、Teable 表单通过受控 iframe 嵌入，保持原产品样式。

## 整体布局

```
+--------------------------------------------------+
| 数字员工 IM 工作台                                |
+----------+---------------------------------------+
| 话题列表  | 话题 tab 栏 · 历史话题 icon            |
| · 新建   | ┌────────┬────────┬───────┐            |
| · 话题A  | │ 话题A  │ 话题B  │ ＋ ❌ │            |
+----------+├───────────────────────────────────────┤
|          | 消息区域                               |
|          | · 历史消息                             |
|          | · Plan/Clarify/胶囊卡片                |
|          | · Clarify 底部选项卡                   |
+----------+---------------------------------------+
| + | 输入框 | 发送                                |
+----------+---------------------------------------+
```

旧版布局（左侧话题列表 + 右侧消息区域）已演进为「话题 tab 栏」形态：用户可通过顶部 tab 同时打开多个话题，通过「历史话题」icon 唤起历史话题列表并新建 tab。详见子需求 [`topic-windows-p0.md`](../../requirements/2026-08-24-issue-17/topic-windows-p0.md)。

## 各区域规格

### 0. 话题 tab 栏与历史话题列表

本区域对应子需求 [`topic-windows-p0.md`](../../requirements/2026-08-24-issue-17/topic-windows-p0.md) 中定义的「按话题拆分多窗口」能力。

#### 话题 tab 栏

- 位置：消息区域顶部，左侧话题列表右侧。
- 元素：
  - 已打开话题 tab：标题 + 关闭按钮。
  - 当前激活 tab 高亮：下划线或背景色变化。
  - 「历史话题」icon：位于 tab 栏最右侧或最左侧，点击后展开历史话题列表。
- 交互：
  - 点击 tab 切换当前激活话题，消息区域加载对应 thread 历史消息。
  - 点击 tab 关闭按钮仅关闭前端视图，不删除 Mattermost thread 数据；关闭后的 tab 可从历史话题列表重新打开。
  - 新发送的消息始终归属当前激活 tab 对应的话题。

#### 历史话题列表

- 触发：点击「历史话题」icon。
- 形态：下拉面板或侧滑抽屉。
- 元素：
  - 历史话题项：标题 + 最后活跃时间 + 未读消息数（可选）。
  - 按最后活跃时间倒序排列。
- 交互：选中话题后在 tab 栏新增 tab 并加载该话题历史消息。

#### Agent 建议创建话题卡片

- 触发：agent 识别到用户新输入与当前话题明显不同。
- 内容：「是否创建新话题讨论「X」？」
- 操作按钮：「创建并切换」「留在当前话题」。
- 自动创建场景：以系统提示形式告知用户「已为你创建新话题「X」」。

### 1. 话题侧边栏

- 宽度：220px，左侧固定。
- 元素：
  - 标题「话题列表」
  - 话题项：标题 + 最后活跃时间/消息数
  - 当前话题高亮（左侧蓝色竖条 + 浅蓝背景）
  - 「+ 新建话题」按钮（虚线边框）
- 交互：点击切换话题；新建话题创建新 Mattermost thread。

### 2. 消息区域

- 占据剩余宽度；消息按 thread 隔离。
- 消息气泡：用户（右侧浅蓝），Agent（左侧灰底）。
- 特殊消息卡片：
  - **Plan 卡片**：白色卡片，展示 markdown 渲染的计划（背景/目标/步骤/依赖/验收标准/风险），底部「通过」「需要修改」按钮。
  - **胶囊消息**：消息内嵌胶囊标签（skill / MCP / 插件 / Teable），可点击展开元信息。
  - **Teable 表单消息**：卡片内含 iframe 占位，下方显示提交结果。
  - **催办卡片**（2026-09-03 新增，F-L10）：发送至责任人话题，含事项摘要（编号/标题/截止时间/逾期状态）与「反馈进展」按钮；催办邮件使用同一文案模板。
  - **每日汇总卡片**（2026-09-03 新增，F-L12）：推送至管理员，按「当日进展 / 已催办及反馈 / 逾期未反馈 / 明日临近截止」四分区展示，每条附跳转对应话题链接。
  - **行文润色确认卡片**（F-L03）：润色结果以 Plan 卡片形态展示，底部「确认填报」「需要修改」按钮。

### 3. Clarify 底部选项卡

- 触发：Agent 调用 Clarify 工具时，在输入栏上方弹出。
- 结构：问题文案 + 3 个推荐选项 + 1 个自定义输入 + 提交按钮。
- 交互：点击选项或填写自定义后提交，以 user message 回传。

### 4. 输入栏

- 高度：约 56px，底部固定。
- 元素：
  - 「+」胶囊选择按钮（圆形）
  - 文本输入框（圆角）
  - 「发送」按钮
- 点击「+」弹出四层/四列胶囊选择面板（Skills / MCP / 插件 / 多维表格）。

### 5. 日程看板

- 入口：侧边栏或聊天内按钮。
- 形态：新页面或右侧抽屉，iframe 嵌入开源日历 UI。
- 视图：月/周/日切换工具栏 + 事件列表侧边栏。

### 6. Token 管理界面

- 表单：授权对象、权限范围、后端类型。
- 列表：Token ID、授权对象、权限、签发时间、撤销按钮。

### 7. 工作台首页（2026-09-03 新增，F-W01~F-W07）

对应子需求 [`workbench-home-p0.md`](../../requirements/2026-08-24-issue-17/workbench-home-p0.md)。

- **定位**：系统默认落地页；与 IM 窗口通过导航与入口互通。
- **布局**：
  - 左侧导航：首页 / IM 数字员工 / 日程（1.7.x 预留）/ 管理端入口（按权限显示）。
  - 主区域三模块：**待办**（页签：审批 n / 督办 m；筛选栏；可跳转列表）、**通知**（信息流 + 未读角标 + 已读确认）、**知识**（检索 + 与我相关聚合）。
  - 底部卡片区：数字员工推送卡片（催办、每日汇总、重要通知）。
- **关键交互**：
  - 审批待办 → OA 审批详情（新窗口/iframe）；督办待办 → IM 对应话题 tab（复用区域 0 tab 机制）。
  - 数字员工头像列表（龙小督等）+ 未读角标，点击进入 IM 窗口。
  - 1.3.1 MVP：待办 + 数字员工入口 + 推送卡片可用；通知/知识模块显示占位卡片（标注 1.4.0 上线）。

### 8. 数字员工管理端（2026-09-03 新增，F-O01~F-O08）

对应子需求 [`org-agent-management-p0.md`](../../requirements/2026-08-24-issue-17/org-agent-management-p0.md)。

- 创建申请表单（岗位/职责/画像/范围四要素）与审批流进度视图。
- 数字员工台账（名称/部门/岗位/负责人/创建时间/活跃度）。
- 技能配置界面（仅人事角色可见）；预设权限包选择。
- 系统级访问清单配置（数字赋能部角色）。
- 具体页面规格在 1.4.0 设计阶段细化，本规格仅约束信息架构与角色可见性。

## 交互规则

- 话题切换：不丢失上下文；新消息归属当前 thread。
- Plan 审批：未点击「通过」前，Agent 不执行关键动作；修改意见驱动 Plan.md 版本递增。
- Clarify：可多轮，每轮生成新的 ClarifySession round。
- 胶囊：仅展示用户/Agent 有权限的对象；非法 schema 显示「无法解析」。
- 日程：Agent 代用户创建事件；多人事件所有参与人可见；Agent 自身事件可触发 Agent 动作。
- 督办闭环（2026-09-03 新增）：催办卡片「反馈进展」直达该「批次-事项」话题输入态；回复润色必须经确认后才写入 Teable（行文风格 Skill 铁则：不脑补、不篡改、保留负面事实）。
- 工作台边界（2026-09-03 新增）：工作台处理个人工作（待办/通知/知识），数字员工处理对外协同；首页内数字员工入口保持显著位置。
