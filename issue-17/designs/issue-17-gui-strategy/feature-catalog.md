# Issue #17 功能目录

## 1. IM 内表单填报（Mattermost + 自研 iframe）

| 功能 | 说明 | 优先级 |
|------|------|--------|
| 表单消息卡片 | 龙小督发送 custom post，内含 iframe 表单 | P0 |
| 多表单翻页 | 一个经办人多条待填报数据，逐条翻页填写 | P0 |
| 字段渲染 | 根据 Teable 字段类型渲染输入控件 | P0 |
| 用户令牌提交 | 提交时携带用户身份令牌，保留操作痕迹 | P0 |
| 提交反馈 | 单条/全部提交后显示成功/失败提示 | P0 |
| 跳转到完整页面 | 提供“在新窗口打开”备选 | P1 |
| 离线保存草稿 | 临时保存未提交数据 | P2 |

## 2. GUI 数据看板

| 功能 | 说明 | 优先级 |
|------|------|--------|
| 督办列表 | 展示所有督办项，支持筛选/排序 | P0 |
| 进度看板 | 按状态（未开始/进行中/已完成/逾期）展示 | P0 |
| 详情抽屉 | 点击某条查看完整信息与历史记录 | P0 |
| 逾期预警 | 高亮即将逾期或已逾期项 | P1 |
| 统计图表 | 完成率、逾期率等 KPI | P1 |
| 导出 | 导出 Excel/PDF | P2 |

## 3. 龙小督能力

| 功能 | 说明 | 优先级 |
|------|------|--------|
| 意图识别 | 判断用户需要填表、查进度、还是审批 | P0 |
| 数据查询 | 通过 Teable API 查询待填报/进度数据 | P0 |
| 表单推送 | 生成 iframe 表单 URL 并发送消息 | P0 |
| 主动提醒 | 基于 Teable 自动化触发催办 | P1 |
| 话题管理 | 多任务上下文隔离（issue #17 未来扩展） | P2 |

## 4. 管理配置

| 功能 | 说明 | 优先级 |
|------|------|--------|
| Teable Base 模板 | 督办、任务、审批等场景模板 | P1 |
| 字段映射 | 配置 Teable 字段与 GUI 表单字段的映射 | P1 |
| 权限模板 | 预设经办人、负责人、领导等角色权限 | P1 |
| 自动化规则 | 逾期提醒、状态流转等 | P2 |

## 5. 安全与审计

| 功能 | 说明 | 优先级 |
|------|------|--------|
| Token 管理 | 用户 token 加密存储与过期刷新 | P0 |
| 操作日志 | 记录谁在什么时间修改了什么数据 | P0 |
| CSP 配置 | iframe 通信与内容安全策略 | P0 |
| 权限校验 | 每次 API 调用都校验用户是否有权操作 | P0 |
