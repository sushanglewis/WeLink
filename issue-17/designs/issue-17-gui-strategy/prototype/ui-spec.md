# Issue #17 原型界面规格

## 原型目标

提供一个可在浏览器中直接打开的静态 HTML demo，演示：
1. Mattermost 聊天窗口中收到龙小督发送的 iframe 表单消息。
2. iframe 内实现多表单翻页（一个经办人 3 条待填报数据）。
3. 每条表单填写后可提交，提交时携带用户身份令牌。
4. 提交完成后，聊天窗口更新确认消息。

## 页面结构

### 1. Mattermost 聊天窗口模拟区

- 顶部：频道标题栏（#督办填报）。
- 中部：消息列表。
  - 龙小督头像 + 名称。
  - 消息气泡，内含 iframe 表单。
- 底部：输入框（仅作展示）。

### 2. iframe 表单区

- 顶部：标题“督办填报” + 进度“第 1/3 条”。
- 中部：当前督办项的表单字段。
  - 事项名称（只读）
  - 截止日期（只读）
  - 进度百分比（数字输入）
  - 填报内容（多行文本）
- 底部：
  - 上一条 / 下一条 翻页按钮
  - 提交按钮（携带用户 token）
- 提交后：显示模拟的 API 请求摘要与成功提示。

## 交互说明

| 交互 | 行为 |
|------|------|
| 页面加载 | 加载 3 条模拟待填报数据，显示第 1 条 |
| 点击“下一条” | 保存当前草稿，翻页到下一条 |
| 点击“上一条” | 保存当前草稿，翻页到上一条 |
| 点击“提交” | 模拟携带 token 调用 Teable API，显示成功提示 |
| 全部提交完成 | iframe 内显示完成摘要，并通过 postMessage 通知父页面 |
| 父页面收到完成事件 | 在聊天列表追加一条龙小督的确认消息 |

## 视觉风格

- 采用 Mattermost 默认暗色主题近似配色。
- iframe 表单采用简洁卡片风格，突出业务字段。
- 提交按钮使用品牌蓝色，禁用状态为灰色。

## 安全示意

- 页面明确标注 token 为模拟值：`Bearer teable_pat_user_xxx`。
- 不连接真实后端。
- 提交时仅在前端展示模拟请求体，不发送任何网络请求。
