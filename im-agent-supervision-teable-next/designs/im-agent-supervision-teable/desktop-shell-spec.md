## 1. 需求（PM 口径）

| # | 需求 | 说明 |
|---|------|------|
| SH-1 | **左侧功能菜单可收起为 icon bar** | 收起后仅保留 icon 窄栏（聊天 / 通讯录 / AI 表格 / 事项看板），hover 显示名称 tooltip；点击 icon 展开对应模块并恢复菜单；再点收起按钮回到 icon bar。展开/收起状态会话内记忆。 |
| SH-2 | **对话列表可收起（L3）** | 对话列表收起后，聊天记录＋插件面板占满主区（PM 布局截图 EG1dLe）；列表右缘保留展开把手；收起时不影响新消息未读提醒与龙小督待办徽标提示。 |
| SH-4 | **聊天记录可收起（L2）** | 聊天记录（聊天面板）可收起，插件面板扩宽（PM 布局截图 kxaMOG）；tab 栏保留可重新展开；与对话列表收起可叠加。 |
| SH-5 | **插件面板可收起（L1）** | 台账插件面板可收起，聊天记录扩宽为单栏（PM 布局截图 igx7ZP）；会话内「台账」tab/徽标点击重新打开（D-14/D-24）。 |
| SH-6 | **输入窗口与聊天窗口共用** | 会话输入窗口=聊天窗口输入框，位于聊天记录＋插件面板**两栏底部横跨**（PM 布局截图 Q8qHT9）；插件面板内**不单独内嵌输入框**（PM 修正）；任一/两个面板收起时输入窗口**持久显示可用**（NL 代填入口不丢，D-24）。 |
| SH-3 | **龙小督条目双徽标** | 聊天列表中龙小督会话除**未读消息数红点**（现有）外，追加**待办事项数量徽标**：绿色数字=当前用户待填报/待查收督办事项数（BFF 聚合，D-14 升级为数徽标）；0 不显示；有催办加急项时转红（D-15）。点击直达会话并打开督办 panel。 |

## 2+. 交互细节

- 收起按钮位于功能菜单底部（sidebar ⇤，共享组件提供，全壳一致）、tab 栏（收聊天/收台账）与对话列表右缘把手；**聊天面板/台账面板收起后成为分隔栏 26px 窄条，窄条本身即展开按钮**（竖排文字+箭头，hover 高亮，点击展开；PM 口径）；快捷键二期。
- icon bar 宽 56px，icon 24px，纵向排列 + 底部用户头像；当前模块高亮角标。
- 聊天列表收起态保留一条 12px 展开把手（hover 展开预览）。
- 待办徽标与未读红点同时存在时：未读红点靠头像（左上），待办数徽标靠条目右侧时间列（与现有督办徽标位置一致），两者样式明显区分。
- 徽标口径与 D-14 一致（BFF 聚合，区别于未读数）；数字随 panel 内提交/批次关闭实时刷新（postMessage `badge_update`）。

## 3. 与本期其他决策的关系

- **D-24**：panel 为表单主载体；SH-2 收起聊天列表后 panel 可达接近全宽，配合 panel 自带 Splitter 覆盖聊天区，形成「全宽专注填报」。
- **D-14/D-15**：徽标从「文字徽标（督办 · N 项待填报）」升级为「数字徽标」，语义不变。
- 本期不改移动端；移动端 WebView 二期（沿用 `embed-form-spec.md` 降级策略）。
