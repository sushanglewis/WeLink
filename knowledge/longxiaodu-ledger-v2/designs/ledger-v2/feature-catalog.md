# 功能目录：龙小督台账 V2

| 编号 | 功能 | 优先级 | 核心验收 |
|---|---|---:|---|
| F-01 | 交办内容展示 | P0 | 只读、三行折叠、四角色可见、空值明确 |
| F-02 | 事项撤回 | P0 | 原督办人、归档前、原因必填、精确到跟进记录 |
| F-03 | 72 小时解除 | P0 | 去重查询忽略已撤回记录，新记录重新计时 |
| F-04 | 批次展示名 | P0 | 截止分钟、+36 小时兜底、稳定序号、全局一致 |

| F-06 | 多批次导出 | P1 | 当前选择即导出范围，任一批次不合格则整体禁止，单 Sheet，成功后统一归档 |
| F-07 | 批次多选统一台账 | P0 | 默认全选未归档批次、事项合集、状态优先级与截止时间排序 |
| F-08 | 提交版本 | P0 | 每次提交不可变、作者与角色可追溯 |

| F-10 | 打回提示 | P0 | 原因、操作人、时间、轮次、待办变化一致 |
| F-11 | 流转记录 | P1 | 提交、打回、撤回按时间展示且只读 |
| F-12 | 龙小督通知 | P0 | 只通知下一动作承担人，内容含事项与原因 |
| F-13 | 节点并发保护 | P0 | 非当前处理人和旧版本操作被拒绝 |
| F-14 | 督办人逐项审核 | P0 | 提交后跟进状态已审核、节点状态督办人已审核 |
| F-15 | 导出即认可 | P0 | 督办人可跳过逐项审核，合格批次导出即统一归档 |
| F-16 | 批次范围快捷选择 | P1 | 全选未归档、仅选可导出、清空 |
| F-17 | 导出后重选 | P1 | 已归档批次取消选择，重新全选剩余未归档批次 |

## 业务质量要求

- **权限清晰**：只有当前节点处理人可提交或打回，只有原发起督办人可撤回。
- **状态一致**：提交、打回、撤回、待办归属和流转记录必须反映同一次业务结果。
- **可追溯**：提交版本和流转记录不可被后续操作覆盖。
- **历史连续**：批次展示名变化不影响事项编号、历史批次和既有导出口径。
- **易于操作**：主要角色能够明确理解当前状态、下一动作和动作影响。
