# 版本记录（issue-dashboard）

本页记录事项看板设计包的定版变更与补充说明，以表格形式归档。最新定版为 **v1.2**（2026-10-08）。各条目与《事项看板 PRD》章节一一对应。

## v1.2（2026-10-08 定版）

| 编号 | 模块 / 范围 | 变更与补充说明 | 关联文档（PRD 章节） |
| --- | --- | --- | --- |
| 1 | 指标卡 | 指标卡仅展示，不可点击交互；且不受下方筛选条件影响，无论怎么筛选，始终按全部事项全量统计（与分页也无关）。 | 第二章「页面指标」三条共同规则 |
| 2 | 筛选条件（10 项定版） | 顺序定版：① 任务名称或编号（关键词模糊搜索，同时匹配名称与编号）→ ② 责任单位、③ 区级责任人、④ 部门责任人、⑤ 部门主管、⑥ 督办人、⑦ 经办人（②–⑦均为模糊搜索多选）→ ⑧ 事项状态（正常 / 风险 / 逾期，默认全选）→ ⑨ 办结状态（已办结 / 未办结，默认全选）→ ⑩ 进度评价（原「状态」改名，推进中 / 已落实 / 已滞后，默认全选）。 | 第四章「筛选条件」 |
| 3 | 事项详情 · 跟进记录 | 跟进记录按创建时间由近及远展示；每条第一行只保留「跟进状态 + 当前节点 + 跟进日期」；不显示填报人、角色徽章、批次编号。 | 第五章「下钻抽屉」 |
| 4 | 跟进记录 · 五要素 | 每条跟进记录下方固定展示五要素：进度评价、预计完成时间、落实情况、存在困难、下一步计划；其中落实情况、存在困难、下一步计划允许为空，空值显示「—」（列表与下钻一致）。 | 第五章「下钻抽屉」 |
| 5 | 跟进记录初始化 | 默认所有事项都有跟进记录；导入的历史数据按导入值初始化一条「事项跟进状态 = 归档」的跟进记录；新导入事项进度评价若为空，默认给「推进中」。 | 第六章「跟进记录初始化规则」 |
| 6 | 统计口径 | 每个事项必有跟进记录，因此「事项总数 = 推进中 + 已落实 + 已滞后」恒成立；「事项总数 = 正常 + 风险 + 逾期」恒成立；明细列表的进度评价列、进度评价筛选，均取该事项最近一条「已归档」跟进记录的值。 | 第二章「核对关系」、第三章「进度评价」列、第四章筛选 ⑩ |
