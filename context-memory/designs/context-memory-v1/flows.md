# 流程设计：写入、回顾、沉降

<!-- status: draft -->

- 设计: context-memory-v1
- 日期: 2026-09-08

## F1 会话内：滚动压缩（②）

```
消息进入 session ──累积──▶ token > 60k 预算？
                              │是                │否
                              ▼                  ▼
                  最早 20% 预算量消息 ──▶ 轻量模型生成滚动摘要
                  替换为上下文头部「准消息」     （用户无感，不打断对话）
                  原文保留于 PG（可回查）
```

## F2 会话后：归档管道（③写入侧）

```
定时扫描 PG last_active_at ──▶ 用户 3h 无消息？
        │是                                        │否
        ▼                                         ▼
生成 archive_task（幂等，按 archive_cursor        跳过
断点）──▶ 轻量摘要 agent 拉取未归档消息 ──▶
识别归属事项 ──┬── 已识别事项 ──▶ append/update {matter_id}.md
               │   （按分段规范，更新 source cursor）
               └── 未识别 ──▶ _misc.md（记录候选主题，供后续升格）
任务标记完成；失败重试（上限 3 次）+ 告警
```

## F3 会话中：回顾（③读取侧，混合触发）

```
激活注入：话题/事项激活 ──▶ 读 INDEX.md ──▶ 注入对应账本「背景+待续事宜」摘要
信号检索：对话中出现旧事信号（事项名/编号、「上次/之前」）
          ──▶ 检索账本 ──▶ 命中则引用并标注「据 N 月 N 日记录」
任务预载：督办定时任务启动 ──▶ 按事项 ID 加载账本+Teable 最新事实 ──▶ 执行
```

## F4 周期：分层沉降（④）

```
每日低峰巡检 ──▶ 事项完结？──是──▶ 生成 summary-card.md（关键决定/承诺/结果/待续）
              │否
              └──▶ 90 天未活跃？──是──▶ 生成 summary-card.md，账本本体转温存
archive/ 规则：摘要卡 1 年未访问 ──▶ 移入 archive/{year}/（检索命中按需加载）
```

## F5 异常与边界

- 摘要失败：任务重试 3 次后告警开发者；`archive_cursor` 不回退，下次续传，不重复记账。
- 多事项穿插对话：单条消息可归属多事项时，在两个账本各记一条摘录互链。
- 用户要求遗忘：删除对应账本条目 + profile 相关偏好，PG 原文保留（合规留痕），账本留删除标记。
- 重启恢复：服务重启后，激活注入路径自动从文件系统重建 INDEX 缓存，无需额外状态。
