# 需求文档: 2026-09-08-context-memory

<!-- status: draft -->

## 背景

- Issue: 暂未创建（后续接 OpenSpec 提案时补链）
- 访谈摘要: `context-memory/interviews/2026-09-08-context-memory/summary.md`
- 关联：issue-17 数字员工工作台（话题管理 F-T01~F-T05、督办场景 F-L01~F-L12）

龙小督是嵌入 IM 组织架构的数字员工 agent（AgentScope 框架自研，7×24 驻留，会话持久化于 PostgreSQL），与组织内多名成员在 DM 中长期对话。人类对他的使用是**场生命周期**的：上线后在一个窗口内持续使用同一个 session 聊天，而非传统 AI 工作台的「开新会话」模式。因此通用的上下文窗口策略、压缩策略、记忆管理方案无法完全适配，需要基于「IM 消息 + Teable 协作」的使用方式重新设计。

## 问题

1. **短周期**：6 小时以内的对话窗口内，用户习惯省略式输入（指代、缩写、承接上文）。若上下文断裂，龙小督无法仅凭近期对话理解用户实际需求。
2. **长周期**：数周/数月/数年的尺度上，用户会就同一督办事项多次与龙小督协作。若没有记忆层，每次隔日/隔周的「新鲜会话」龙小督都从零开始，协作背景（当时的决定、承诺、偏好、进展）全部丢失。
3. **业务事实与记忆混杂**：Teable 台账中的是可查询的业务事实，但「用户说过什么、答应过什么、当时为什么这么定」不在任何系统里，需要额外的 agent 记忆层承载。
4. **agent 主动场景**：督办定时任务、催办、每日汇总等 agent 主动发起的会话，同样需要预载对应事项的背景才能不「失忆」。

## 用户

- **组织成员（龙小督的 DM 对话用户）**：短周期内获得连续、无需重复交代背景的对话体验；长周期内被龙小督「记得」与该用户、该事项相关的协作历史。
- **PM/管理员**：督办业务正常运转，龙小督在主动通知/催办/汇总时不丢上下文、不闹笑话。
- **开发者/运维**：能在服务器上直查记忆文件，审计龙小督「为什么这么做」。
- 注：本期仅覆盖 DM 场景，不做群聊；规模假设为几十人 / 几百事项。

## 方案

全栈四层设计（详见设计阶段文档）：

1. **会话管理层**：基于现有 PostgreSQL 会话持久化，定义窗口策略与跨重启恢复方式，保证 6 小时内功能性连续。
2. **滚动压缩策略**：session 持续增长时，早期消息滚动摘要压缩、近期消息保持原文，对话不中断、无感切换。
3. **账本记忆层（核心）**：龙小督在自己的空间维护 `.md` 账本，以「用户 × 督办事项」为锚（批次为事项的维度信息）记录协作背景。写入管道：捕获用户 3 小时不活跃事件 → 轻量模型摘要 agent 拉取未归档对话 → 总结写入对应事项的 `.md` 账本。回顾采用混合触发（话题/事项激活注入、对话中旧事信号检索、督办任务执行前预载）。技术路线通过方案对比确定：自研 `.md` 账本 vs Graphiti vs mem0，按场景契合度、运维成本、集成难度、可审计性、规模演进空间评分并给出对接设计。
4. **分层沉降**：活跃事项保留详细账本；完结事项压缩为事项级摘要卡；长期未活跃归档冷存，检索时按需加载。

边界：Teable 仍是业务事实源（经 Teable skills 查询），不充当记忆存储；账本对普通用户黑盒，开发者可服务器直查；轻量摘要模型选型在设计阶段确定（倾向小参数模型）。

## 验收标准

- [ ] 验收标准一（连续性）：6 小时窗口内的多轮对话中，用户省略式/指代式输入被龙小督正确理解，无需重复交代背景。
- [ ] 验收标准二（滚动压缩）：会话超长触发滚动压缩后，近期消息保持原文、早期消息以摘要保留，对话可无缝继续。
- [ ] 验收标准三（归档管道）：用户 3 小时不活跃后，未归档对话被轻量摘要 agent 按规范写入对应事项的 `.md` 账本，摘要准确、结构合规。
- [ ] 验收标准四（长周期回顾）：隔日/隔周的新会话中提及旧事项时，龙小督能凭账本回顾并正确引用当时的背景、决定与承诺。
- [ ] 验收标准五（主动场景）：督办定时任务/催办/每日汇总执行前自动加载对应事项背景，产出内容不丢上下文。
- [ ] 验收标准六（沉降）：完结事项自动沉降为摘要卡，冷存事项可按检索加载。
- [ ] 验收标准七（方案对比）：记忆层方案对比文档含自研 `.md` 账本 / Graphiti / mem0 三方案的场景化评分表与明确推荐，含对接设计。
- [ ] 验收标准八（可审计）：开发者可在服务器按目录规范直查记忆文件，无需登录任何额外系统。
