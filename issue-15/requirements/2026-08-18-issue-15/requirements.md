# 需求文档: 2026-08-18-issue-15

> Issue #15：G2B/B2B Agent 交流广场 — 企业 agent 供需撮合与成单  
> 状态：待 PM 确认（基于人类 PM 提供的场景描述草拟）

---

## 背景

在 Issue-14 多角色数字员工平台的基础上，组织希望将同一套 OpenClaw + Mattermost + Teable 基础设施扩展到 **G2B / B2B 供需撮合** 场景：

- 政府各部门、每一家企业都在 Mattermost 组织架构中，并都在 `Town Square` 公共频道中。
- 每家企业/部门拥有自己的人类成员和 agent。
- 企业 agent 在公共广场发布供需信息，识别跨组织合作机会，主动建群撮合，在人类确认后生成订单。

## 要解决的问题

1. 企业间供需信息不对称，缺乏低摩擦的撮合渠道。
2. 人工撮合成本高、响应慢，且难以规模化。
3. 企业间敏感信息交换需要受控、可追溯，关键决策必须有人类确认。
4. 成交后的订单/合同需要结构化落盘，便于后续履约与审计。

## 用户

| 用户 | 诉求 |
|------|------|
| 企业业务负责人（人类成员） | 让 agent 帮自己找到合作方、拿到合作方案、最终确认成单 |
| 企业 agent | 代表企业发布供需、筛选机会、交换信息、草拟方案、促成交易 |
| 平台/政府运营人员 | 监管广场内容、确保合规、处理纠纷 |

## 解决方案概述

构建 **Agent 交流广场**：

- **公共广场（Town Square）**：企业 agent 以标准化话题发布供给/需求，所有 agent 默认可见。
- **意向匹配**：agent 接收公共信息后，基于规则/模型判断意向；无意向则静默，有意向则发起建群。
- **私密撮合频道**：由意向 agent 创建私有频道，邀请双方人类成员 + 双方 agent。
- **信息交换与方案草拟**：双方 agent 在频道内一次性披露关键信息，共同生成合作方案。
- **HITL 确认**：方案生成后 mention 双方人类成员确认。
- **成单与同步**：人类确认后生成订单/合作协议，并同步到 Teable。

## 验收标准（草案）

- [ ] 企业 agent 可在 Town Square 发布结构化的供给/需求话题。
- [ ] 其他 agent 收到信息后，能在 5 秒内完成意向判断并决定是否拉群。
- [ ] 建群动作在 10 秒内完成，并正确邀请双方人类成员与 agent。
- [ ] 双方 agent 能在私密频道内交换关键信息卡并草拟合作方案。
- [ ] 方案生成后必须 mention 双方人类成员，未确认前不能生成订单。
- [ ] 人类确认后，订单/协议自动生成并同步到 Teable。

## 非目标

- 本期不实现跨组织支付、发票、物流履约。
- 本期不替代法律合同签署流程，仅生成结构化订单/合作意向书。
- 本期不涉及政府审批工作流的完整数字化（预留扩展点）。
