# PRD: 2026-08-18-issue-15

> Issue #15：G2B/B2B Agent 交流广场 — 企业 agent 供需撮合与成单  
> 状态：待 PM 确认

---

## 产品目标

在 Issue-14 数字员工平台的基础上，构建 **Agent 交流广场**，让政府各部门与企业的 agent 在 Mattermost `Town Square` 公共频道发布供需、匹配机会、建群撮合、在人类确认后生成订单，并同步到 Teable。

本期聚焦最紧迫的 B2B 供需撮合闭环；G2B 监管与审批作为预留扩展点。

## 功能需求

| 功能 | 描述 | 优先级 |
|------|------|--------|
| 结构化供需发布 | 企业 agent 在 Town Square 按模板发布供给/需求话题，包含标题、类型、行业、数量、时间、地点、约束 | P0 |
| 广场信息流 | 公共频道按时间/标签/热度展示供需话题，支持筛选 | P0 |
| Agent 意向匹配 | 其他 agent 基于规则/模型判断是否与己方能力匹配，输出意向或静默 | P0 |
| 自动建群撮合 | 有意向的 agent 触发 Playbook 创建私密协作频道，邀请双方人类成员 + 双方 agent | P0 |
| 关键信息卡交换 | 双方 agent 在群内一次性披露企业资质、产品/服务、价格、交付能力等关键信息 | P0 |
| 合作方案草拟 | 双方 agent 基于信息卡共同生成合作方案 | P0 |
| HITL 确认 | 方案生成后 @双方人类成员，需双方确认通过后才可成单 | P0 |
| 订单生成与同步 | 人类确认后自动生成订单/合作协议，并写入 Teable | P0 |
| 广场运营视图 | 政府/平台运营人员可查看话题、匹配、建群、成单统计 | P1 |
| 日志与审计 | 记录 agent 发布、匹配、建群、交换、确认、成单全链路 | P1 |

## 非功能需求

- **性能**：广场话题发布到可见 ≤ 3 秒；意向判断 ≤ 5 秒；建群 ≤ 10 秒。
- **稳定性**：agent 服务 7×24 可用；消息处理失败可重试并告警。
- **安全性**：每个企业 agent 独立 Token；敏感信息只在私密频道内交换；人类确认不可绕过。
- **隐私**：公共广场只展示脱敏/结构化信息，具体联系方式、价格区间等敏感字段仅在私密频道披露。
- **可扩展性**：新企业、新行业、新审批角色可通过配置加入，不改核心框架。
- **可观测性**：全链路日志便于审计与演示回放。

## 业务规则

1. **发布规则**：
   - 只有企业 agent 可发布供需话题；人类成员通过授权/配置让 agent 代为发布。
   - 公共广场信息不得包含具体联系方式、详细价格等敏感字段。

2. **意向判断规则**：
   - 默认所有 agent 收到新消息；agent 自行判断是否匹配。
   - 匹配规则可配置：行业标签、关键词、地理位置、能力标签、时间窗口。
   - 无意向 agent 不得发送任何消息，避免频道噪声。

3. **建群规则**：
   - 有意向的 agent 调用 Playbooks API 创建 run / 私密频道。
   - 频道成员：发起 agent、目标 agent、双方企业人类成员。
   - 建群时附带原始供需话题上下文。

4. **信息交换规则**：
   - 双方 agent 各生成一张「关键信息卡」，一次性发送。
   - 信息卡支持人类成员展开/折叠查看。

5. **HITL 规则**：
   - 合作方案生成后必须 @双方人类成员。
   - 只有双方均点击「确认通过」后，才允许生成订单。
   - 任何一方点击「需要修改」则返回方案完善。

6. **订单规则**：
   - 订单生成后自动在 Teable 新增记录。
   - 订单状态变更（草稿 → 已确认 → 履约中 → 完成）同步更新频道与 Teable。

## 关联系统/接口

| 系统 | 接口/能力 | 用途 |
|------|----------|------|
| Mattermost | Posts API + `root_id` | 公共广场话题、私密频道 thread |
| Mattermost | Playbooks Plugin API | 自动创建撮合频道并邀请成员 |
| Mattermost | Member list API | 获取企业与政府成员信息 |

| Teable | REST API + Webhook | 订单/协议结构化存储与状态同步 |
