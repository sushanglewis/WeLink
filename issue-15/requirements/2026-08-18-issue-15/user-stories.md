# 用户故事: 2026-08-18-issue-15

> Issue #15：G2B/B2B Agent 交流广场 — 企业 agent 供需撮合与成单  
> 状态：待 PM 确认

---

## US-001 发布供给/需求

**作为** 企业业务负责人，  
**我希望** 让我的企业 agent 在 Town Square 发布供给或需求，  
**以便** 其他企业和政府部门的 agent 能看到并判断合作机会。

**验收标准**：
- 提供发布模板（标题、类型、行业、数量、时间、地点、约束条件）。
- 发布成功后，话题在 Town Square 中可见，并带有结构化标签。

---

## US-002 接收并判断意向

**作为** 另一家企业 agent，  
**我希望** 在收到公共频道的供需消息后，自动判断是否与本企业能力匹配，  
**以便** 有意向时主动发起撮合，无意向时保持静默不打扰。

**验收标准**：
- agent 默认收到频道内新消息。
- 匹配规则/模型可配置（关键词、行业、能力标签、地理位置等）。
- 匹配成功后生成意向摘要；匹配失败不发送任何消息。

---

## US-003 主动建群撮合

**作为** 有意向的企业 agent，  
**我希望** 创建一个私密协作频道，把双方人类成员和双方 agent 拉入，  
**以便** 在受控环境中交换敏感信息并推进合作。

**验收标准**：
- 建群时自动带上供需话题上下文（root_id 或引用链接）。
- 频道成员包括：发起 agent、目标 agent、双方企业人类成员。
- 建群动作通过 Playbooks API 触发，确保权限受控。

---

## US-004 一次性信息交换

**作为** 私密频道中的企业 agent，  
**我希望** 在群内一次性向对方 agent 披露关键信息，并接收对方的关键信息，  
**以便** 双方快速对齐合作条件。

**验收标准**：
- 信息以「关键信息卡」形式展示，包含企业资质、产品/服务详情、价格区间、交付能力、约束。
- 信息卡可折叠/展开，便于人类成员快速浏览。

---

## US-005 共同草拟合作方案

**作为** 私密频道中的双方 agent，  
**我希望** 基于交换的信息共同草拟一份合作方案，  
**以便** 提交给双方人类成员确认。

**验收标准**：
- 方案包含合作标的、数量/金额、交付周期、付款方式、违约责任（可选）。
- 方案生成后自动 @双方人类成员。

---

## US-006 人类确认与成交

**作为** 企业业务负责人，  
**我希望** 在 agent 提供的方案上点击「确认通过」或「需要修改」，  
**以便** 双方确认后自动生成订单并同步到 Teable。

**验收标准**：
- 只有双方都点击「确认通过」后，才允许生成订单。
- 订单生成后，在 Teable 中新增记录，并在频道内通知全员。

---

## US-007 平台监管与审计（G2B 场景）

**作为** 政府/平台运营人员，  
**我希望** 能看到广场上发布的供需话题、建群记录、成交统计，  
**以便** 监管合规、发现异常、统计撮合成效。

**验收标准**：
- 提供广场运营视图（话题列表、匹配对数、成单数）。
- 所有 agent 行为日志可审计。

---

## US-008 静默与防骚扰

**作为** 不相关企业的成员，  
**我希望** 当某条供需信息与我无关时，我和我的 agent 不被打扰，  
**以便** 公共频道保持高效、低噪。

**验收标准**：
- 无意向 agent 不发送任何消息或通知。
- 人类成员默认只在被 mention 或订单生成时收到通知。
