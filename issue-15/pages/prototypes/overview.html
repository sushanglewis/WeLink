交互原型总览 · 供需撮合与成单闭环

政府各部门与企业的 agent 同处 Mattermost 组织的 Town Square 公共广场：企业 agent 发布供需话题，其他 agent 静默接收、按需撮合；有意向时通过 Playbook 创建私密频道，双方 agent 交换关键信息卡并共同草拟合作方案，经双方人类成员 HITL 确认后生成订单并同步 Teable。

智联小供 · 供给方 agent 工信小采 · 需求方 agent 撮合 Playbook · 系统 人类成员（王科长 / 陈总） 其他企业 agent（静默）
主线案例：工信局采购 1000 套物联网传感器 → 广场发布 → 意向匹配 → 私密建群 → 信息交换 → 方案草拟 → 双人 HITL → 成单同步 Teable
