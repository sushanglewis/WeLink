# 批次多选与统一台账视图交互设计

<!-- status: approved -->

## 设计结论

取消「按批次 / 平铺模式」切换，将批次选择、事项查看和批量导出统一到同一个台账视图中。

批次下拉框改为多选控件。用户进入台账时，默认选中全部未归档批次；下方事项卡展示所选批次的事项合集。当前选择范围同时决定台账展示范围和 Excel 导出范围，避免用户在导出弹窗中发现异常后再跳回台账处理。

## 设计目标

1. 用户进入台账即可看到全部仍需推进的事项，无需在批次模式和平铺模式之间切换。
2. 用户通过勾选批次直接控制事项卡展示范围。
3. 用户在同一页面发现并处理阻塞导出的事项，不发生弹窗跳转造成的场景中断。
4. 导出对象始终与用户当前选中的批次一致，不出现部分导出或隐式排除。
5. 已归档批次仍可回看，但不干扰默认工作范围。

## 批次选择

### 默认选择

- 用户首次进入台账时，默认选中全部未归档批次。
- 已归档批次保留在批次下拉列表中，但默认不选中。
- 用户可手动选择已归档批次查看历史事项。
- 没有未归档批次时，不默认选择任何批次，并提示「暂无未归档批次，可从批次列表查看历史记录」。

### 快捷操作

批次下拉列表提供以下操作：

- **全选未归档**：选择全部未归档批次，不选择已归档批次。
- **仅选可导出**：只保留当前符合导出条件的未归档批次。
- **清空**：取消全部选择，下方事项区显示空选择提示。

### 批次选项信息

每个批次选项展示批次名称及完整事项构成：

`共 N 项 · 已撤回 N 项 · 已填报 N 项 · 已审核 N 项 · 已归档 N 项 · 待处理 N 项`

其中：

- 「共 N 项」包含已撤回事项。
- 「已撤回 N 项」单独展示，避免总事项数与实际导出数不一致。
- 「待处理 N 项」包括尚不满足导出要求的跟进中和逾期未填报事项。
- 「已归档 N 项」用于准确说明历史批次，不计入待处理。
- 各分类数量之和应与总事项数一致。
- 批次同时显示「可导出」「暂不可导出」或「已归档」结论。

## 事项卡合集

- 下方事项区展示当前所有选中批次的全部事项，包括已撤回事项。
- 事项卡保持现有单行横向排列，支持左右拖动和左右按钮切换。
- 每张事项卡增加所属批次名称，避免多批次事项混淆。
- 卡片继续在右上角展示事项跟进状态，在左下角展示事项节点状态。
- 事项排序依次为：逾期未填报、跟进中、已填报、已审核、已归档、已撤回。
- 同一状态内先按填报截止时间由近及远排序，再按批次序号和事项编号稳定排序。
- 用户调整批次选择后，事项卡合集立即按新的选择范围重新呈现。

## 导出规则

### 导出资格

同时满足以下条件时，导出按钮可用：

1. 至少选择一个批次。
2. 所选批次全部为未归档批次。
3. 所选每个批次中的全部非撤回事项均处于「已填报」或「已审核」。

任一选中批次不满足条件时，整体禁止导出，不自动忽略、不部分导出。用户可以继续处理阻塞事项，也可以取消选择不满足条件的批次。

### 不可导出提示

- 导出按钮附近明确显示「所选批次中有 N 个暂不可导出」。
- 批次下拉列表标明具体不可导出的批次及其待处理事项数。
- 下方事项卡已经展示相关阻塞事项，用户可直接选择事项继续提交、打回或推进。
- 选择了已归档批次时，提示「已归档批次仅供查看，请取消选择后导出」。
- 未选择批次时，提示「请至少选择一个未归档批次」。

## 导出确认

导出弹窗不再承担批次选择，只用于确认当前导出范围和归档影响。

确认信息包括：

- 所选批次数。
- 所选批次总事项数。
- 已撤回事项数。
- 实际参与导出并归档的事项数。
- 固定说明「导出即代表认可所选批次，并归档其中全部非撤回事项」。

示例：

> 将导出 2 个批次，共 7 项；其中已撤回 1 项不参与导出，实际导出并归档 6 项。

## 导出完成

- 导出成功后，所选批次转为已归档并自动取消选择。
- 页面重新默认选中全部剩余未归档批次。
- 若已无未归档批次，显示未归档批次空状态。
- 成功提示明确展示批次数、总事项数、实际导出数和已撤回未导出数。
- 用户仍可在批次下拉列表中手动选择刚归档的批次进行回看。

成功提示示例：

> 已导出并归档 2 个批次，共 7 项；实际导出 6 项，已撤回 1 项未导出。

## 与原有设计的关系

- 删除「按批次 / 平铺模式」视图切换。
- 删除平铺模式的偏好记忆规则。
- 删除导出弹窗中的批次复选列表。
- 保留现有台账页面层级、横向事项卡、事项详情和底部操作区。
- 保留平铺模式原有的事项状态优先排序，并将其作为统一台账视图的排序规则。
- 导出仍然只属于督办人操作，仍表示批次级认可和归档。

## 验收标准

- [ ] 进入台账时默认选中全部未归档批次，已归档批次默认不选中。
- [ ] 下方事项卡完整展示所选批次的事项合集，并标明所属批次。
- [ ] 批次总事项数包含已撤回事项，并单独展示已撤回数量。
- [ ] 「全选未归档」「仅选可导出」「清空」符合各自定义。
- [ ] 任一选中批次不满足条件时，整体禁止导出且明确说明原因。
- [ ] 取消选择阻塞批次后，其余合格批次可以导出。
- [ ] 选择已归档批次时只能查看，不能执行导出。
- [ ] 导出确认弹窗不再提供批次选择，只核对范围和归档影响。
- [ ] 导出成功后已归档批次自动取消选择，并重新选中剩余未归档批次。
- [ ] 页面不再出现「按批次 / 平铺模式」切换。
