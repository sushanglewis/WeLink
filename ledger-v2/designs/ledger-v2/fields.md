# 字段规格：龙小督台账 V2

> 本文只说明界面字段的业务含义、展示和校验规则。

## 批次区域

| 字段/控件 | 是否必需 | 展示与业务规则 |
|---|---:|---|
| 跟进批次 | 是 | 支持多选；展示 `YYYY-MM-DD HH:mm-N`；默认全选全部未归档批次 |
| 批次快捷选择 | 否 | 全选未归档、仅选可导出、清空 |
| 督办下达日期 | 是 | 只读 |
| 填报截止日期 | 是 | 只读；未提供时按下发后 36 小时形成 |
| 批次事项计数 | 是 | 展示总事项、已撤回、已退回、已填报、已审核、已归档、待处理；总事项包含已撤回 |
| 导出 Excel | 督办人可见 | 当前选择即导出范围；任一选中批次不合格或已归档则整体禁用 |

## 事项卡

| 字段 | 位置 | 展示规则 |
|---|---|---|
| 事项编号 | 左上 | 同一事项在不同批次中分别展示 |
| 场景注脚 | 卡片右下 | Axure 风格黄色编号角标，与原型本体区分；鼠标移入悬浮展示该卡片模拟的场景说明（如「督办人打回经办人」「打回后下游再提交」） |
| 事项跟进状态 | 右上 | 跟进中、已退回、已填报、已审核、已归档、逾期未填报、已撤回 |
| 交办事项 | 中部 | 超出卡片宽度省略 |
| 事项节点状态 | 左下 | 使用已确认的九个节点状态；有待办承担人时追加「· 承担人姓名」 |
| 截止时间 | 左上 | 显示「截止 YYYY-MM-DD HH:mm」；不显示所属批次，批次概念仅督办人可见 |
| 横向浏览 | 是 | 所有所选批次卡片单行排列，支持左右拖动、左右按钮和当前序号 |
| 已撤回 | 右上（跟进状态第七值）+ 左下（节点状态第九值） | 右上显示「已撤回」，左下显示「督办人已撤回」，详情节点状态显示「撤回前：<节点状态>」；记录不参加导出和待办 |

## 事项详情

| 字段/控件 | 是否必需 | 展示与校验 |
|---|---:|---|
| 交办事项 | 是 | 只读标题 |
| 交办内容 | 否 | 只读；空值显示「暂无交办内容」；超过三行可展开/收起 |
| 协作者 | 是 | 按督办人、经办人、转办人、次级转办人顺序展示；黄色圆点为当前处理、绿色白勾为当前轮次已提交、灰色圆点为未提交或提交已失效；不存在的角色显示「—」且无角标 |
| 部门反馈工作落实情况 | 是 | 提交时不能为空 |
| 部门反馈存在困难问题 | 是 | 没有困难可填写「无」 |
| 部门反馈下一步工作计划 | 是 | 提交时不能为空 |
| 预计完成时间 | 是 | 提交时不能为空 |
| 进度评价 | 是 | 跟进中、已落实、已滞后单选 |
| 流转记录 | 是 | 默认展开；标准格式记录：姓名、角色、操作、秒级时间戳；提交内容可展开收起；打回/撤回附完整原因评论 |

## 操作字段

| 操作 | 条件 | 必填信息 | 结果 |
|---|---|---|---|
| 提交 | 当前节点归属本人 | 五项填报内容 | 认可当前内容并向上流转；督办人提交后为已审核/督办人已审核 |
| 打回 | 待上游提交；或收到上游打回且仍有直接下游 | 打回原因 | 退回实际直接下游，事项跟进状态置为已退回；保留原内容和历史版本；可逐级继续向下打回 |
| 转办 | 经办人或转办人当前处理，且事项从未被打回 | 转办对象 | 建立既有责任链；事项一旦发生打回，后续永久隐藏转办入口 |
| 撤回事项 | 原发起督办人且未归档 | 撤回原因 | 退出待办、导出和 72 小时限制 |
| 多批次导出 | 督办人 | 至少选择一个批次且全部选中批次合格 | 非撤回的已填报/已审核记录统一归档；导出后重选剩余未归档批次 |

## 批次多选与导出确认

| 字段 | 展示规则 |
|---|---|
| 批次勾选 | 位于台账批次下拉框；默认勾选全部未归档批次，已归档批次可手动查看 |
| 批次名称 | 使用截止时间展示名及稳定序号 |
| 完成情况 | 展示总事项、已撤回、已填报、已审核、已归档、待处理和不可导出原因 |
| 快捷选择 | 全选未归档、仅选可导出、清空 |
| 导出确认 | 只展示批次数、总事项数、已撤回数、实际导出数及归档影响，不提供批次选择 |
| 导出说明 | 固定提示「导出即认可并归档」 |
